# Консилиум

Плагин для [Claude Code](https://claude.com/claude-code).

Прежде чем ответить, ваш вопрос внимательно обдумают 11 агентов Claude. Это как совет, где каждый смотрит со своей стороны: один — с милосердием, другой — со строгостью, третий думает о деле, четвёртый — о том, как сказать честно и бережно. Ответы опираются на источники Торы.

Этот порядок вдохновлён взаимодействием сфирот, как его описывает Каббала. Агенты называются качествами — «качество Хесед», «качество Гвура» — в духе Тании (гл. 3), где говорится о десяти силах души человека, соответствующих сфирот. Мы не утверждаем, что агенты «включают» сами сфирот.

## Как это работает

**Вход.** Прежде чем передать вопрос консилиуму, агент входа задаёт несколько уточняющих вопросов: отделяет факты от толкований, ищет вопрос под вопросом и вместе с человеком формулирует суть. На приветствие или простой вопрос он отвечает сразу, без консилиума. В консилиум уходит переписка — **слова человека дословно**, без пересказа.

**Консилиум** — по порядку:

| # | Роль | Что делает |
|---|---|---|
| 1 | Суть · качество Кетер | что человек хочет на самом деле, критерии хорошего ответа |
| 2 | Идеи · качество Хохма | 5–7 коротких неожиданных идей |
| 3 | Анализ · качество Бина | развивает идеи, видит следствия, отбрасывает слабые |
| 4 | Главное · качество Даат | выбирает 1–3 главные мысли |
| 5 | Поддержка · качество Хесед | самый щедрый вариант ответа |
| 5 | Проверка · качество Гвура | риски, границы, сверка каждой цитаты с оригиналом |
| 6 | Мера · качество Тиферет | сводит щедрость и строгость в верную меру |
| 7 | Действие · качество Нецах | конкретные шаги |
| 7 | Честность и подача · качество Ход | что честно признать, тон и форма |
| 8 | Сборка · качество Йесод | собирает всё в единый план ответа |
| 9 | Ответ · качество Малхут | пишет ответ строго по плану |
| 10 | Итоговая проверка · качество Кетер | сверяет ответ с сутью вопроса; если нужно — один круг доработки |

Агенты с одинаковым номером работают одновременно. Каждый читает слова человека и работу предшественников.

## Источники Торы

Каждый агент сам обращается к кошерной библиотеке источников — в своём качестве: Поддержка ищет источники милости и надежды, Проверка сверяет цитаты по оригиналу и ищет границы, Действие — практические наставления мусара, и т.д.

- **Что в библиотеке:** Танах и комментаторы, Мишна, Талмуд, Мидраш, Рамбам, Шулхан Арух, мусар, еврейская философия, хасидут, Каббала (как источник смысла).
- **Духовные практики** (Теилим, молитвы, тикуны, сгулот) — из белого списка: [silatehilim.com](https://silatehilim.com), с указанием первоисточника, на который ссылается статья, и ссылкой на страницу. Если сайт недоступен из вашей сети, агенты читают его через r.jina.ai или Web Archive.
- **Где ищут:** тексты Сефарии через её API (пользовательские листы исключены) и ортодоксальные сайты: chabad.org, aish.com, ou.org, torah.org, hebrewbooks.org, yeshiva.org.il, dinonline.org, breslov.org, inner.org, daf-yomi.com, silatehilim.com.
- Каждая цитата помечается как сверенная по оригиналу или нет; выдуманные источники запрещены.
- Практическая галаха: консилиум объясняет, но решение — за вашим раввином.

Источники включены по умолчанию. Выключить на один вопрос:

```
/sefirot --без-источников Ваш вопрос
```

## Установка

Нужен установленный [Claude Code](https://claude.com/claude-code) и подписка Claude. В Claude Code:

```
/plugin marketplace add lavrentynevenchany/sefirot
/plugin install sefirot@sefirot
```

Перезапустите Claude Code.

## Использование

```
/sefirot Ваш вопрос
```

или просто `/sefirot` — и опишите вопрос в ответ на приглашение.

Если у вас уже есть другая команда с именем `sefirot`, используйте полное имя: `/sefirot:sefirot`.

Уточняющие вопросы занимают несколько минут, работа консилиума — около 15–25 минут. Все агенты работают на Claude Opus — это заметно расходует лимит подписки. Записи каждого агента и итоговый `answer.md` сохраняются в `~/Desktop/Сфирот/<дата>_<тема>/`.

## Настройка

Характер каждого агента — в файле `agents/sefira-<имя>.md` (агент входа — `agents/sefirot-gate.md`): модель, глубина мышления и инструкция. Порядок работы — в `skills/sefirot/SKILL.md`.

> Ответы готовит модель, а не раввин. Это помощник в размышлении, а не псак и не учение. Чтобы изучать Тору и Каббалу, учитесь с раввином.
